# TerraSentry — Agent Instructions

Repo architecture, stack decisions, and conventions live in `docs/architecture.md`.
Use `pnpm` for JS/TS work and `uv` for Python work. Run `pnpm check` before
finishing a change.

# Documentations
- use the find-docs skill to query necessary documentations using context7.


# Coding standards

- TypeScript is strict and Effect-first for domain/runtime code: services + Layers, `Schema` at
  boundaries, `Schema.TaggedError` for typed failures. Never `any` or raw `throw` across a service
  seam.
- Python is async-first and fully typed. Deterministic logic (scoring, status derivation) stays in
  code, never in prompts. Ruff and Pyright must be clean.
- `packages/api-client/openapi.json` and `src/schema.d.ts` are generated by `pnpm gen:api`; never
  edit them by hand.
- Keep tests next to the code they cover; run `pnpm check` before finishing any change.

# Learning more about Effect

This repository uses the Effect Typescript library.

Before writing any Effect code, first read `node_modules/effect/AGENTS.md`
**completely**, and follow the links in the file when required.

If you need to learn more about particular Effect apis and concepts that the
guide doesn't cover, search through the source code in `node_modules/effect/src`.

# UI conventions

- UI is Tailwind CSS v4 with shadcn/ui on Base UI primitives (`style: base-mira`,
  `apps/web/components.json`). Use the shadcn skill in `.agents/skills/shadcn` when
  adding or fixing components; always run the CLI with `pnpm dlx shadcn@latest`.
- All design tokens live in `apps/web/src/styles.css` (single source of truth,
  mapped from `DESIGN.md`). Never create another theme file or hardcode colors;
  use semantic tokens (`bg-background`, `text-muted-foreground`, `text-display-sm`,
  `border-outline-on-dark`, `text-status-risk`, ...).
- The app is dark-only. Registry components may import from `"cn"`; rewrite those
  imports to `#/lib/utils` and remove the bogus `cn` dependency if it appears.
